Low-end engine settings:
The list of renderer switches turned off on the Low quality level follows the community "Coalesced_INT"
low-end mod for Xenia, published on ModDB. No file of that mod and no game file is included; the values
are changed in the user's own game files at run time and saved to a cache folder.
